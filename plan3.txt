Vercel deployment plan from now
Frontend app: `Arya/client`
1. Create a new Vercel project from the `client` folder.
2. Set build command to `npm run build`.
3. Set output directory to `dist`.
4. Add environment variable `VITE_BASEURL` with the deployed backend URL.
5. Deploy, then verify client-side routes work by refreshing on nested pages.

Backend app: `Arya/server`
1. Create a separate Vercel project from the `server` folder.
2. Keep the source entrypoint in `Arya/server/api/[...all].ts`.
3. Set build command to `npm run build`.
4. Add required env vars: `DATABASE_URL`, `BETTER_AUTH_URL`, `BETTER_AUTH_SECRET`, `TRUSTED_ORIGINS`, `STRIPE_SECRET_KEY`, `STRIPE_WEBHOOK_SECRET`, and any OpenAI/Gemini keys used by the server.
5. Deploy and test `/api/auth`, `/api/user`, `/api/project`, and `/api/stripe/webhook`.

Important order
- Deploy backend first so you have the live API URL.
- Point `VITE_BASEURL` in the frontend to that backend URL.
- Redeploy frontend after updating the env var.

Quick verification after deploy
- Open the frontend home page.
- Sign in and confirm auth cookies work.
- Load projects and preview pages.
- Test one backend action such as saving a project or publishing a project.
